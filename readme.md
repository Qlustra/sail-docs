# Sail documentation

Sail lets a Go framework use the same tagged model to declare a grammar and to
hold the result of interpreting an application’s struct declarations.

- [Sail manual](manual/readme.md) — the Legend, Chart, and Navigator mental
  model, followed by the library’s capabilities in dependency order.
- [Runnable examples](examples/readme.md) — small tasks and complete framework
  examples, with commands and expected output.
- [Sail Go API](https://pkg.go.dev/github.com/qlustra/sail) — call signatures and
  preconditions.
- [Legend marker API](https://pkg.go.dev/github.com/qlustra/sail/legend) — types
  for authoring a grammar.
